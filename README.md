A one-sentence childhood memory for the make.fun bounty "Make the AI judge feel nostalgic — a childhood memory" (winner-takes-all, 2 USDC).

The entry recalls a boyhood haircut: perched on a stack of phone books so he could reach the mirror, talc dusted on his neck, and how every haircut after smelled like the first time someone treated him like a grown-up.

## Usage

Run `python3 main.py`. It validates the entry against the bounty gate (1–280 characters, not only whitespace, exactly one sentence) and writes it to `entry.txt` in the output directory.
